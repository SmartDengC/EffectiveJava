## 二叉树的简单了解

最多只有左右两个节点的树，没有父节点的我们称只为跟节点，子节点组成的树称为子树，没有子节点的节点称为叶子节点；
从跟节点到叶子节点的最大距离我们称之为树的高度。

### 满二叉树

所有的节点都有两个子节点。
假设深度为h，那么总节点就是2^h-1。

### 完全二叉树

是指二叉树的每一层都紧凑靠左排列，除了最后一层，其他每层都必须是满的。

### 二叉搜索树

左子树所有节点的值都小于根节点的值，右子树所有节点的值都大于根节点的值。
不能只看子节点，要看整颗树的所有节点。
下面的二叉树就不是二叉搜索树：

```angular2html
 7
/ \
4   9
/ \   \
1   8   10
```

### 平衡二叉树

是指每个节点的左右子树的高度差的绝对值不超过1。
假设平衡二叉树中共有N个节点，那么平衡二叉树的高度是O(logN)。这是非常重要的性质，如何能保证树的高度是O(logN)
，那么这些数据结构的增删查改效率会很高。

### 自平衡树

那么我们就可以在增删二叉树节点时，对树的结构进行一些调整，使得树始终是平衡的。这种自平衡的二叉树有很多种，最经典的就是
红黑树，一种自平衡的二叉搜索树。
